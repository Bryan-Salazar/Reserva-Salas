# Sistema de Reserva de Salas

Sistema web para la gestión y reserva de salas de clases con control de horarios y prevención de cruces.

## 🚀 Características

- Sistema de login con roles (ADMIN y USUARIO)
- Reserva de salas con validación anti-cruces de horario
- Gestión de asignaciones por unidad académica
- Panel administrativo para gestión de salas y usuarios

## 🛠️ Tecnologías

- **Backend:** Node.js + Express
- **Base de datos:** SQLite3
- **Frontend:** HTML, CSS, JavaScript (Vanilla)

## 📦 Instalación Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Iniciar servidor de producción
npm start
```
